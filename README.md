# Jules Game World 🎮

一个包含多种emoji主题小游戏的合集项目。

## 游戏列表

- **Emoji Match Master** - 消消乐游戏，在限定时间内匹配相同的emoji
- **Emoji Collector** - 收集游戏
- **Emoji Tic-Tac-Toe** - emoji版井字棋游戏

## 项目结构

```
Jules-Game-World/
├── index.html          # 主页面
├── emoji-match-master/ # 消消乐游戏
├── emoji-collector/    # 收集游戏
├── emoji-tic-tac-toe/ # 井字棋游戏
└── shared/            # 共享资源
```

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript
